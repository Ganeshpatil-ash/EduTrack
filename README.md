# 🎓 EduTrack – Student Management System

A modern full-stack MERN application for managing students, courses, attendance, and academic records. Built with React, Node.js, Express, MongoDB, and JWT Authentication.

## 🚀 Features

### Authentication & Security

* JWT Authentication
* Password Hashing with bcrypt
* Protected Routes
* Role-Based Access Control

### Student Management

* Add, Edit, Delete Students
* Student Profile Management
* Department & Semester Filtering
* Search & Pagination

### Course Management

* Course CRUD Operations
* Instructor Assignment
* Semester-wise Organization

### Attendance System

* Mark Daily Attendance
* Bulk Attendance Management
* Attendance Analytics
* Attendance History Tracking

### Dashboard & Analytics

* Real-time Statistics
* Student Enrollment Insights
* Attendance Trends
* Department-wise Distribution
* Interactive Charts & Graphs

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Ganeshpatil-ash/EduTrack.git
cd EduTrack
```

### Backend Setup

```bash
cd backend
npm install
npm run dev
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## 🔐 Environment Variables

Create a `.env` file inside the backend folder:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
JWT_EXPIRES_IN=7d
```
